# Remote_Photoplethysmography_AI_Detection
Inspired by the fakecatcher project by Dr. Umur Ciftci and Ilke Demir, Using tiny changes in skin color to detect if the video is a deepfake.

Data:
S. Bobbia, R. Macwan, Y. Benezeth, A. Mansouri, J. Dubois, "Unsupervised skin tissue segmentation for remote photoplethysmography", Pattern Recognition Letters, 2017.
